# Code of Conduct

## The short version

Be decent to people. Assume they are acting in good faith. Criticise code, not
the person who wrote it.

## Not acceptable

Harassment, insults, or personal attacks. Sexualised language or imagery.
Publishing anyone's private information. Sustained disruption of discussions.
Any of it in issues, pull requests, commit messages, or anywhere else connected
to this project.

## Scope

This applies in all project spaces, and when representing the project elsewhere.

## Reporting

Report a problem to the repository owner through a GitHub issue, or privately via
the Security tab if it involves personal information you would rather not post.
Reports are handled as privately as the situation allows.

Consequences range from a request to stop, through having a comment removed, to
being blocked from the repository — proportionate to what happened, and decided by
the maintainer.

## A note on scale

This is a personal project maintained by one person. There is no committee and no
formal appeals process; there is just someone trying to be fair. Adapted in spirit
from the [Contributor Covenant](https://www.contributor-covenant.org).
